# 🏌️ 高尔夫智能分析系统

一个专为高尔夫爱好者设计的移动端数据分析工具，支持成绩记录、趋势分析、得分率统计和 AI 建议。

---

## ✨ 功能特性

- 📝 **成绩录入** — 快速记录每洞成绩、发球准确率、推杆数、沙坑/障碍次数
- 📊 **数据分析** — 自动计算总杆数、得分率、标准杆达成率
- 📈 **趋势图表** — 可视化展示杆数趋势、各洞表现、推杆分布
- 🎯 **AI 建议** — 基于数据分析提供个性化的改进建议
- 📱 **移动端优化** — 针对手机浏览器优化，支持 iOS Chrome

## 📱 使用方法

### 1. 清除浏览器缓存（首次使用）
如果是更新后的版本，建议先清除手机浏览器缓存，避免加载旧版文件。

### 2. 录入成绩
- 选择日期（日期框已优化，不会溢出屏幕）
- 选择球场名称
- 录入 18 洞的成绩和相关数据
- 点击"添加本轮成绩"

### 3. 查看分析
- 切换到"数据分析"标签页
- 查看总杆数、得分率、趋势图表
- 获取 AI 改进建议

### 4. 管理历史
- 切换到"历史成绩"标签页
- 查看所有历史记录
- 可以删除不需要的记录

## 🛠️ 技术栈

- **前端框架**：纯 HTML + CSS + JavaScript（无依赖）
- **图表库**：Chart.js 4.4.7（CDN 引入）
- **数据存储**：localStorage（浏览器本地存储）
- **移动端适配**：响应式设计，针对 iOS Chrome 优化

## 🐛 已知问题与修复

### 日期输入框溢出问题（已修复 ✅）
- **问题**：在 iOS Chrome 浏览器上，日期输入框会溢出卡片边界
- **原因**：手机浏览器缓存严重，一直加载旧版
- **解决方案**：
  1. 把日期框从 grid 布局中独立出来，独占一行
  2. 宽度设为 `90%`，加 `box-sizing: border-box`
  3. 卡片加 `overflow: hidden` 兜底
